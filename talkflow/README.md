# TheBox Talk Flow

Talk Flow는 운영일별 회화 토픽을 생성하고 검수한 뒤 학생용·리더용 A4 자료로 출력하는 정적 운영 도구입니다. 새 토픽은 Conversation-First 생성 경로와 Simple Conversation v3 두 페이지 구조를 사용하며, 저장된 이전 형식 토픽은 자동 변환하지 않습니다.

## 로컬 실행

저장소 루트에서 정적 서버를 `8766` 포트로 실행하고 `http://127.0.0.1:8766/`을 엽니다.

```powershell
python -m http.server 8766 --directory talkflow
```

기본 화면은 `해야 할 일`입니다. 전역 메뉴는 `토픽 준비`, `일괄 인쇄`, `설정` 세 개이며 학생용·리더용 화면은 선택한 날짜 안에서 엽니다.

## 운영 흐름

1. `해야 할 일`에서 생성 실패, 검수 필요, 승인 가능, 미작성 순서로 작업을 확인합니다.
2. 미작성 운영일의 `토픽 만들기`에서 주제를 입력해 Topic Plan과 Content Fill을 생성합니다.
3. `내용 검수`에서 Story, 질문, 표현, Activity와 최종 질문을 확인하고 필요한 섹션만 수정하거나 다시 생성합니다.
4. 학생용·리더용 탭에서 각 두 페이지를 확인합니다.
5. 차단 오류가 없을 때 승인하고, 개별 PDF 또는 `일괄 인쇄`를 사용합니다.

`전체 월`은 운영일만 주차별로 표시하고, `달력`은 상태 확인과 날짜 선택에만 사용합니다. 브라우저 뒤로가기·앞으로가기와 새로고침은 현재 view, 날짜, 탭, 페이지를 복원합니다.

## 인쇄

개별 학생용과 리더용은 각각 A4 세로 두 페이지입니다. 일괄 인쇄에서는 승인 완료 토픽만 선택할 수 있고 학생용, 리더용, 학생용 + 리더용의 예상 페이지 수를 표시합니다. 인쇄 대화상자에서는 배경 그래픽을 켜고 용지를 A4, 배율을 100%로 사용합니다.

## 데이터와 비밀값

토픽, 설정, 버전, 피드백은 Talk Flow 전용 localStorage 키에 저장됩니다. JSON 내보내기는 API 키와 Gist token을 포함하지 않습니다. 설정 화면은 저장된 비밀값을 input 또는 DOM에 다시 넣지 않으며, 변경 모드에서 새 값을 입력할 때만 교체합니다.

Gist 동기화는 승인 토픽의 월별 JSON과 읽기 전용 viewer 파일을 사용합니다. 기존 승인 토픽, 실패 초안, 이전 형식 토픽과 `/topics/`는 자동 수정하지 않습니다.

## 문제 해결

- 생성 버튼이 비활성화되면 설정의 AI 연결에서 모델 목록과 연결 테스트를 확인합니다.
- 401 오류는 키 변경으로 새 API 키를 저장한 뒤 한 번만 다시 확인합니다.
- 생성 실패 화면의 기술 상세에서 실패 섹션을 확인하고 해당 섹션만 다시 생성합니다.
- PDF가 세 페이지가 되면 브라우저 인쇄 배율과 여백을 확인하고 `print-qa.mjs`를 다시 실행합니다.
- 공개 Preview에서는 보안을 위해 직접 Anthropic 연결과 생성이 비활성화됩니다.

## QA

핵심 회귀 검사는 `auth-regression-qa.mjs`, `connection-qa.mjs`, `model-qa.mjs`, `simple-qa.mjs`, `generation-engine-qa.mjs`, `conversation-qa.mjs`, `qa.mjs`, `navigation-qa.mjs`, `print-qa.mjs`로 실행합니다. 생성되는 `.qa-pdf`와 `.omo/evidence` 파일은 검수용이며 커밋하지 않습니다.
